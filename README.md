# java-gym-master
Repository for homework project.

ТЗ: реализовать хранение расписания занятий, а также:
 - получение всех тренировок, упорядоченных по времени начала, за конкретный день недели. Требуемая алгоритмическая сложность O(1);
- получение всех тренировок, начинающихся в конкретное время, за конкретный день недели. Для этого запроса допустима сложность O(log(n)) или быстрее.
- добавление новой тренировки в расписание. Новая тренировка может быть добавлена для любого дня недели и любого времени. Ограничения относительно - алгоритмической сложности отсутствуют;
 - посчитать, сколько занятий в неделю ведёт каждый из тренеров. Тренеры должны быть упорядочены по количеству тренировок по убыванию.
